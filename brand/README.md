# Brand source files

`brandora-logo-source.png` is the original Brandora lockup: the serif B lit
along its inner edges in metallic purple, over near-black, with the wordmark in
letterspaced silver capitals.

The site does not load this file. It is 1.7MB, and a logo that costs a customer
on metered mobile data 1.7MB to see is a logo that does not get seen. The
lockup was rebuilt as vector from this reference and lives in
`apps/brandora/assets/img/`:

| File | Use |
| --- | --- |
| `logo-full.svg` | The full lockup — mark and wordmark |
| `logo-b-solid.svg` | The mark alone, for the header |
| `favicon.svg` | The mark at favicon scale |

Keep this PNG as the reference the vectors are checked against.
